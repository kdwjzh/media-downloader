# App 圖示

> 定案日期：2026-11-19
> 圖形：LR1「方框變進度」（第四輪，L 方唱片與 R 進度環的混搭）
> 顏色以 `design-system/media-downloader/MASTER.md` 為準；這裡只列圖示用到的四色。

## 1. 想法

唱片做成圓角正方形，對應 App 裡「MP3 縮圖是正方形」的規則。中間的方框是唱片的溝槽，同時也是一條進度條：
從正上方順時針走到四分之三，表示「下載中」。中心的芥末黃是唱片標籤。
不用箭頭、雲、播放三角形與紅色（跟 YouTube 與這類工具的套路分開）。

## 2. 檔案

| 檔案 | 用途 |
|---|---|
| `logo/app-icon.svg` | 主檔，32 px 以上 |
| `logo/app-icon-small.svg` | 小尺寸版（16、20、24 px）：方塊較滿、溝槽較粗、標籤較大 |
| `logo/app-icon-mono.svg` | 單色梅紫（溝槽與標籤是鏤空的） |
| `logo/app-icon-black.svg`、`logo/app-icon-white.svg` | 單色黑、單色白 |
| `icons/app.ico` | Windows 用：16、20、24、32、40、48、64、256 px。exe、捷徑、安裝程式都用它 |
| `icons/app-<尺寸>.png` | 同上各尺寸的 PNG，另有 512 |
| `concepts/` | 四輪的所有樣稿與總覽圖，只是紀錄，不要拿來用 |

## 3. 顏色與對比

| 顏色 | 色碼 | 在圖示裡 | 對白 #FFFFFF | 對黑 #000000 | 對淺色工作列 #F3F3F3 | 對深色工作列 #202020 |
|---|---|---|---|---|---|---|
| 梅紫 | `#6B2D5C` | 方塊 | 9.74 | 2.16 | 8.78 | 1.67 |
| 墨紫 | `#231A24` | 進度剩下的那段、標籤中心孔 | 16.87 | 1.24 | 15.20 | 1.04 |
| 芥末黃 | `#F2C230` | 唱片標籤 | 1.68 | 12.53 | 1.51 | 9.73 |
| 淡梅紫 | `#EFE6F0` | 進度已完成的部分 | 1.22 | 17.25 | 1.10 | 13.38 |

圖示內部的組合：

| 前景／背景 | 對比 |
|---|---|
| 淡梅紫／梅紫（進度條） | 8.00 |
| 芥末黃／梅紫（標籤） | 5.82 |
| 墨紫／芥末黃（中心孔） | 10.07 |
| 墨紫／梅紫（進度剩下的那段） | 1.73 |

圖形的門檻是 3:1。要知道的地方：

- **深色底上，梅紫方塊的外緣只有 1.67（#202020）／2.16（黑）**，低於 3:1。在深色工作列上認得出來，靠的是方塊裡的淡梅紫進度條（13.38）和芥末黃標籤（9.73），不是方塊的外緣。這是刻意的取捨：不為了對比去改顏色或加外框。
- 墨紫／梅紫只有 1.73：「還沒完成的那一段」本來就要比較不顯眼，不是要被看見的形狀。
- 淺色底上，芥末黃與淡梅紫都在梅紫方塊裡面，不直接碰到底色。

## 4. 尺寸

- 最小 16 px。16、20、24 px 用 `app-icon-small.svg` 畫出來的版本（`app.ico` 裡已經是）。
- 32 px 以上用 `app-icon.svg`。
- 進度的意思（那一小段墨紫）大約 32 px 以上才看得出來；更小時看起來是一個有方框和黃點的梅紫方塊，這是預期的。
- 圖示本身就是方塊，不需要另外留白；放在 App 內時，周圍至少留 8 px。

## 5. 不要這樣用

- 不要換顏色、加漸層、陰影、光澤或外框。
- 不要放在梅紫或接近梅紫的底色上（方塊會消失）；必要時用單色白版。
- 不要拉長、壓扁、旋轉、裁切。
- 不要加箭頭、文字、播放三角形或紅色。
- 不要把芥末黃當成方塊的底色，或把芥末黃的面積放大。
- 不要改進度的長度或起點（固定從正上方順時針到四分之三）。
- 不要重畫；需要圖示時用這個資料夾裡的檔案。

## 6. 重新產生 PNG 與 .ico

改了 SVG 才需要。PNG 用 logo-design skill 的 `render_png.py`（無頭 Chrome）算繪；`.ico` 用 `scripts/make_ico.py` 打包（只用標準函式庫）。

```
python <logo-design>/scripts/render_png.py brand/logo/app-icon-small.svg -o brand/icons/app-16.png --size 16
（20、24 同上，用 app-icon-small.svg；32、40、48、64、256、512 用 app-icon.svg）
python scripts/make_ico.py brand/icons/app.ico brand/icons/app-16.png brand/icons/app-20.png brand/icons/app-24.png brand/icons/app-32.png brand/icons/app-40.png brand/icons/app-48.png brand/icons/app-64.png brand/icons/app-256.png
```

單色黑、白版用 `export_variants.py logo/app-icon-mono.svg --name app-icon --only black white` 產生。
