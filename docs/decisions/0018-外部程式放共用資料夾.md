# 0018. 外部程式放在共用資料夾，安裝檔用 Inno Setup

- 日期：2026-11-19
- 狀態：已採用（取代 0005）

## 背景

`0005` 決定把 yt-dlp、FFmpeg、Deno 放在 App 的安裝資料夾，並留下一個問題：重新安裝或升級 App 時，安裝檔附的 yt-dlp 可能比使用者已經更新過的還舊。
階段 5 決定發佈方式是 Inno Setup 安裝檔加上 App 內的自動更新（`docs/階段5-計畫.md`）。App 更新就是重跑安裝程式，安裝資料夾會被整個換掉。

5a 實測與查證：

- `yt-dlp.exe` 有 Windows 版本資訊（FileVersion `2026.10.26`，數字版本 `2026.10.26.0`）；FFmpeg 沒有，Deno 有。
- Inno Setup 不加 `ignoreversion` 時會比較版本：已存在的檔案一樣新或比較新就不換，比較舊才換。
- FFmpeg-Builds 的每日建置只留約兩週，但每個月底的建置一直留著（2024-12 起都在）。
- 同一版 FFmpeg 的 shared 建置（ffmpeg.exe 加 7 個 DLL）約 184 MiB，比 static 的 ffmpeg.exe（162 MiB）大；BtbN 的 LGPL 建置 zip 只小約 13%。

## 決定

1. **外部程式放 `%LOCALAPPDATA%\media-downloader\bin`**（打包後）。開發時仍用 repo 的 `bin\`。路徑只由 `infrastructure/binaries/` 決定。
2. **安裝程式放外部程式**：yt-dlp 不加 `ignoreversion`，靠 Inno 的版本比較，不把使用者更新過的換回舊版；FFmpeg、Deno 加 `ignoreversion`，一律換成這一版測過的版本。
3. **解除安裝一律刪掉 `bin`**（含 `yt-dlp.exe.old`）；設定、歷史、記錄檔詢問，預設留下，靜默解除安裝時留下。
4. **外部程式不見時**：App 啟動時檢查三個檔案，少了就用中英對照的訊息框請使用者重新安裝並結束。不加錯誤代碼；使用中才不見的仍是「未知錯誤」。
5. **FFmpeg 固定用月底的 static GPL 建置**（`autobuild-2026-10-31-18-18`），不附 ffprobe，不用較小的建置。原始碼的取得方式寫在 `packaging/licenses/FFmpeg-SOURCE.txt`。
6. **安裝檔**：Inno Setup 7，「僅目前使用者」安裝、不需要系統管理員權限、開始功能表捷徑、語言跟隨系統（繁中、英文）。
   App 開著時用 `AppMutex` 請使用者自己關掉，不讓安裝程式強制關閉。沒有 WebView2 時提示微軟的下載網址，讓使用者決定要不要繼續。
7. **版本號**以 `backend/app/__init__.py` 的 `__version__` 為準；`pyproject.toml` 由測試擋住不一致，安裝檔由打包腳本傳入。

## 理由

- 共用資料夾不在安裝資料夾裡，App 更新不會碰到它；使用者把 App 裝在哪裡也不影響 yt-dlp 的自我更新。
- yt-dlp 自己有版本資訊，用 Inno 內建的比較就好，不用寫程式。
- 啟動時檢查比在每個錯誤裡分辨「程式不見」簡單，而且不改約定、服務層、介面；重新安裝會把缺的檔案補回來（檔案不存在時一定會放）。
- 月底建置有版號又會留著，可以重現；較小的建置實測省不了空間，自己編譯是另一個專案。
- 強制關閉 App 會打斷正在進行的下載。

## 考慮過的其他做法

- 維持 `0005`（放在安裝資料夾）：App 更新會把 yt-dlp 蓋回舊版，要另外寫比較與保留的邏輯。
- 安裝程式不放 yt-dlp、第一次啟動才下載：要網路才能第一次使用。
- 新增錯誤代碼 `missingProgram` 在介面顯示：要改約定、`types.ts`、兩份語言檔。
- 附微軟的 WebView2 安裝程式並自動執行：Windows 11 與更新過的 Windows 10 都有，測不到又多一個要維護的檔案。

## 後果

- 解除安裝後，使用者手動放進 `bin` 的東西也會被刪。
- 月底建置哪天被刪掉，打包腳本會在下載時失敗，要換一個月底的版本，並一起改 `FFmpeg-SOURCE.txt`。
- 使用中才被刪掉的外部程式只會顯示「未知錯誤」。
- `1.0.0-rc.1` 這種版本號在新版檢查裡一律當成「沒有新版」（`parse_version` 只認三個整數），rc 測試期間看不到新版；5b 改成照語意化版本比較（`0019`）。
- 安裝程式在 Windows Sandbox 裡測不到「沒有 WebView2」的情況。
