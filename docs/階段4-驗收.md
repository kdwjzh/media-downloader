## 3. 第二步：交接第 4 節真視窗驗的兩項

- 第 34 項（`npm run build` 後不加 `--dev`）：頁面由 pywebview 的本機伺服器提供、資源都在本機、沒有 Vite 與檢查面板；重新載入畫面正常；真的下載中關閉 → 確認視窗 → 繼續下載 → 再關 → 停止並關閉，App 結束、沒有殘留程序與 `.md-tmp-*`。
